Use case: ui-mockup
Asset type: high-fidelity north-star composition for a desktop manager application
Primary request: Design the Reglet Manager Library workbench using the Raycast visual design system as the pinned authority. This is composition option A: a dense, persistent four-region workbench for daily editing and projection inspection.
Structure, in order: a compact 48px top title/command bar spanning the window; a 168px left navigation sidebar; a 300px searchable artifact list; a flexible central Markdown editor/preview; a 340px right projection inspector. A restrained 34px action footer shows keyboard shortcuts and the neutral Apply action.
Real content: brand “Reglet”; navigation “Library”, “Project Inbox”, “Providers”, “Activity”, “Settings”; filters “Active”, “Drafts”, “Archived”, “Needs attention”; selected artifact “General agent instructions”; provider rows “Codex”, “Claude Code”, “Cursor”, “Gemini CLI”, “Windsurf”, “OpenCode”; projection states “Applied”, “Pending”, “Drifted”, and “Not targeted”; actions “Preview diff” and “Apply changes”.
Interaction hierarchy: the selected artifact row is a quiet coral-tinted surface, not a solid coral fill. The central editor is dominant. The right inspector visibly compares Desired, Applied, and Observed revisions and shows one shadowing warning. Apply is a Mist light-gray button with dark text; never a colored CTA.
Visual system: match Raycast’s midnight command-center design language—#040506 canvas, #07080a elevated surfaces, #111214 input wells, hairline #2f3031 borders, subtle inset top highlights, tactile keyboard-key inner-shadow stack, Inter/SF-like typography, compact 12–14px interface labels, Geist-like mono only for hashes and shortcuts. Coral #ff6363 appears only in the Reglet mark, selected-state punctuation, and one warm warning surface. 8px controls, 12–16px large regions. Achromatic, polished, native-macOS feeling.
Composition/framing: exact straight-on 1440×960 desktop application viewport; render the interface itself, no monitor, no device bezel, no room, no perspective. High fidelity and production credible.
Constraints: information-dense but calm; clear keyboard focus; no status conveyed by color alone; no raster illustration; no invented analytics or metrics; no marketing hero.
Avoid: generic SaaS dashboard, grids of equal cards, glassmorphism as decoration, chromatic buttons, blue accent, broad gradients, thick shadows, excessive pills, giant headings, code-editor clone, rounded rectangle around every section, watermark.
