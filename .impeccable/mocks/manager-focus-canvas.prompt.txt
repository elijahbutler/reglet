Use case: ui-mockup
Asset type: high-fidelity north-star composition for a desktop manager application
Primary request: Design the Reglet Manager using the Raycast visual design system as the pinned authority. This is composition option C: a focused artifact canvas with progressive disclosure—editing gets maximum space, while provider projection state lives in a compact bottom shelf that expands on demand.
Structure, in order: a 48px top title/command bar with breadcrumbs and global command trigger; a compact 52px icon navigation rail; a 320px artifact library pane with search and lifecycle filters; one broad central artifact editor occupying most of the viewport; a 112px projection shelf across the bottom of the editor showing six provider state cells; a narrow 280px contextual issue drawer appears only for the selected drifted provider. A small keyboard action bar closes the window.
Real content: brand “Reglet”; navigation tooltips “Library”, “Project Inbox”, “Providers”, “Activity”, “Settings”; selected artifact “General agent instructions”; tabs “Edit”, “Preview”, “History”; provider cells “Codex · Applied”, “Claude Code · Pending”, “Cursor · Drifted”, “Gemini CLI · Applied”, “Windsurf · Not targeted”, “OpenCode · Pending”; issue heading “Shadowed by AGENTS.override.md”; actions “Open external file”, “Preview diff”, and “Apply changes”.
Interaction hierarchy: the editor and its actual Markdown content dominate. Provider cells behave like compact tactile keys, not cards; selecting Cursor opens the issue drawer. The selected artifact and selected provider use only a quiet coral tint and small coral punctuation. Apply is a neutral Mist button with dark text, never coral. The Project Inbox badge indicates 3 items without becoming a metric card.
Visual system: match Raycast’s midnight command-center design language—#040506 canvas, #07080a elevated surfaces, #111214 input wells, hairline #2f3031 borders, subtle inset top highlights, tactile keyboard-key inner-shadow stack, Inter/SF-like typography, compact 12–14px interface labels, Geist-like mono only for paths, hashes, Markdown, and shortcuts. Coral #ff6363 appears only in the Reglet mark and selected-state punctuation. 8px controls, 12–16px large regions. Achromatic, polished, native-macOS feeling.
Composition/framing: exact straight-on 1440×960 desktop application viewport; render the interface itself, no monitor, no device bezel, no room, no perspective. High fidelity and production credible.
Constraints: information-dense but calm; clear keyboard focus; no status conveyed by color alone; no raster illustration; no invented analytics or metrics; no marketing hero.
Avoid: generic SaaS dashboard, grids of equal cards, glassmorphism as decoration, chromatic buttons, blue accent, broad gradients, thick shadows, excessive pills, giant headings, code-editor clone, rounded rectangle around every section, watermark.
