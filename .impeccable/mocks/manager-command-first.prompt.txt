Use case: ui-mockup
Asset type: high-fidelity north-star composition for a desktop manager application
Primary request: Design the Reglet Manager using the Raycast visual design system as the pinned authority. This is composition option B: a command-first workspace where global search and actions are the primary navigation, with a fast result list and contextual detail.
Structure, in order: a centered 1120px application window inside the viewport; a prominent 56px command/search well across the top with the query “needs attention”; a 390px grouped result list below on the left; a broad contextual detail/preview pane on the right; a compact action footer with keyboard shortcuts. A slim icon rail reveals Library, Project Inbox, Providers, Activity, and Settings without consuming a full sidebar. The selected result is “General agent instructions · Cursor drifted”.
Real content: brand “Reglet”; search placeholder “Search artifacts, providers, and actions”; result groups “Library”, “Project Inbox”, and “Providers”; items “General agent instructions”, “Cursor rule · src/**”, “Codex”, “Claude Code”; detail headings “Projection drift”, “Desired”, “Applied”, “Observed”; actions “Open artifact”, “Preview diff”, “Reapply”, and “Ignore”. Clearly show that a project rule is read-only and that Apply is explicit.
Interaction hierarchy: command input is the focal point; result rows are highly scannable and keyboard-selected. The selected row has a quiet coral tint and a 1px coral punctuation edge. The detail pane is calm, mostly flat, and supports a line-level diff. Primary action is a neutral Mist button with dark text, never coral.
Visual system: match Raycast’s midnight command-center design language—#040506 canvas, #07080a elevated surfaces, #111214 input wells, hairline #2f3031 borders, subtle inset top highlights, tactile keyboard-key inner-shadow stack, Inter/SF-like typography, compact 12–14px interface labels, Geist-like mono only for paths, hashes, diff lines, and shortcuts. Coral #ff6363 appears only in the Reglet mark and selected-state punctuation. 8px controls, 12–16px primary frame. Achromatic, polished, native-macOS feeling.
Composition/framing: exact straight-on 1440×960 desktop application viewport; render the interface itself, no monitor, no device bezel, no room, no perspective. High fidelity and production credible.
Constraints: information-dense but calm; clear keyboard focus; no status conveyed by color alone; no raster illustration; no invented analytics or metrics; no marketing hero.
Avoid: generic SaaS dashboard, grids of equal cards, glassmorphism as decoration, chromatic buttons, blue accent, broad gradients, thick shadows, excessive pills, giant headings, code-editor clone, rounded rectangle around every section, watermark.
